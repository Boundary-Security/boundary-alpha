# Security Policy

Boundary is currently an experimental controlled private alpha.

## Reporting a vulnerability

Please do not disclose suspected Boundary vulnerabilities through public GitHub issues.

Report security concerns privately to:

**info@boundarysec.com**

When possible, include:

- affected Boundary version;
- operating environment;
- MCP implementation involved;
- expected behavior;
- observed behavior;
- reproduction steps;
- potential security impact.

We will review reports and coordinate disclosure when appropriate.

## Current security status

Boundary is experimental software and is not currently intended to serve as a production security boundary.

Boundary reasons about the system represented by its configuration and runtime model. Its conclusions therefore depend on the accuracy and completeness of modeled agents, capabilities, information flows, derivations, communication paths and safety invariants.

The controlled alpha is intended for evaluation, adversarial testing and research feedback.
