# Boundary Controlled Private Alpha

Boundary is currently available to selected external evaluators through a controlled private alpha.

The protected Boundary implementation is not contained in this public repository.

## Current evaluation build

- Boundary 0.0.1 alpha 2
- Linux x86_64
- Python 3.14
- Experimental / non-production

Selected evaluators receive a platform-specific compiled runtime under separate evaluation terms.

The private source repository, protected implementation, internal research code and internal benchmark suite are not distributed.

## What we are testing

The alpha is intended to evaluate whether predictive multi-step reachability provides useful security properties for real autonomous-agent and MCP systems.

We are especially interested in:

- real MCP integrations;
- multi-agent systems;
- sensitive-data workflows;
- adversarial scenarios;
- false positives;
- false negatives;
- modeling limitations;
- comparisons with existing authorization and policy systems.

Critical feedback and counterexamples are welcome.
